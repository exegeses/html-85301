# Flexbox - sistema de contenedores flexibles
Cuando queremos distribuir el contenido dentro de un contenedor tenemos varias técnicas.
Una de las técnicas más potentes y más fáciles de usar es la de Flex Box (el sistema de contenedores flexibles)

Comenzamos activando Flex Box con
```css
display:flex;
```

La primera consecuencia del *display:flex;* es que los elementos de bloque (que se ubican uno debajo del otro) ahora se van a ubicar uno al lado del otro.
